# Perfboard build instructions

Generated by `hardware/tools/wire_list.py` from `clearair.kicad_pcb`. Regenerate after you move parts.

Hole name = column letter + row number, like `E7`. Columns are letters along the long side (A, B, C ...), rows are numbers along the short side, as printed on the perfboard. Look at the component side (**top**) with the long side horizontal: the corner A + last row is at the **top right**, column A is at the right and row 1 at the bottom. The name of a hole is the same from both sides: from the **back** (solder side, where all wires go) the board is turned over left to right, so A is at the left. Board 2 is shown rotated 90° clockwise, so it lies landscape (in KiCad it is portrait). 

Board 1: 24 columns (A to X) x 18 rows.
Board 2: 24 columns (A to X) x 18 rows.
